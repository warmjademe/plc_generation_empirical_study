# PLC 生成服务交付测试报告（2026-08-24）

## 1. 结论

本轮测试覆盖需求准入、契约生成、候选生成、MatIEC、PLCverif、OpenPLC、ISPSoft/COMMGR、可下载工程、历史记录、任务取消、恢复、并发调度、认证和外部 HTTPS 入口。当前版本具备受控试运行条件，但不能将仿真结果表述为真实硬件安全验收；正式现场投产前仍需完成真实 PLC 点检和安全回路验收。

## 2. 自动化与确定性验证

- 隔离候选全量测试：274 passed，1 skipped。唯一跳过项依赖 Node.js；同一路径已由生产地址上的真实 Firefox 桌面端与移动端测试覆盖。
- 验证链预检：已知正确程序通过接口检查、MatIEC、PLCverif、OpenPLC 可见测试和 OpenPLC 确认测试；已知错误程序被语义验证拒绝。
- 需求边界矩阵：21/21 个不完整、矛盾、提示注入或恶意标记输入在调用模型前返回 422。
- 凭据扫描：部署源代码目录未发现 API key、PAT、私钥或同类明文凭据。

## 3. Windows 厂商验证池

- 4 个 Windows worker 均在线、空闲并通过准入，DVP48ES300R 与 AS228T-A 在每个节点上均显示可用。
- 双型号节点校准：4 节点 × 2 型号，共 8 组正反例 canary 全部通过。
- 并发资源池：同时提交 5 个厂商任务时，最大活动租约严格为 4；前 4 个任务分配到 4 个不同节点，第 5 个任务排队约 222 秒后接管释放节点；5/5 通过。
- 长租约测试：同一节点连续执行 3 个周期、每周期覆盖两个型号，共 6 次厂商验证，全部通过且租约未串扰。

## 4. 真实模型端到端矩阵

- Claude Sonnet 5 功能单元模式：5/5 通过，覆盖 DVP48ES300R、AS228T-A、ST、LD 和不同控制需求；候选消耗为 1、1、3、1、1。
- Claude Sonnet 5 的 AS228T-A 可下载工程补测：LD 1/1 通过；ST 在 3 个候选内未满足固定接口/响应结构，按功能失败记录，未误记为基础设施错误或验证成功。
- DeepSeek Pro 的组合 REAL 阈值控制：DVP48ES300R 和 AS228T-A 均通过完整验证链，分别消耗 1 个和 2 个候选。
- 测试发现保留型 INT 计数输出超出当前契约 Oracle 的表达能力。系统已增加确定性前置检查：此类需求现在会在模型调用前返回可操作的 422 诊断，不再耗尽 10 次契约生成预算，也不会产生弱 Oracle 假阳性。

## 5. Web、历史记录与恢复能力

- 外部 HTTPS 入口返回 200，并启用 HSTS、CSP、禁止嵌入、MIME 嗅探防护、权限策略和无引用来源策略。
- 未认证 API 被拒绝；错误登录被拒绝；正确登录、安全 Cookie 属性和会话访问已验证。
- 历史记录的服务端分页、日期/状态/型号/程序类型/模型筛选、关键词搜索、详情查看、文件下载、归档、恢复和删除均已验证。
- 幂等提交、用户取消、Web 服务重启后任务续跑、执行进程重启后的租约恢复以及契约预算恢复均已验证。
- 前端保存任务 ID 和幂等提交信息；刷新页面或临时断网后可重新关联后台任务。
- 现场复测发现，可下载工程等待人工确认时，较长的实时日志会把物理 I/O 确认区推到首屏之外。现已改为该状态直接显示契约、I/O 映射和确认按钮，并更新静态资源版本以避免旧浏览器缓存继续加载缺陷页面。
- 修复后使用生产地址和真实 Firefox 分别在 1366×768 桌面视口及 390×844 手机视口执行界面级测试。两种视口中实时日志均不会遮挡确认表单；I/O 表和确认项可见，完成两个确认项后按钮可启用并滚动到可点击区域。测试未点击最终确认，因此没有创建真实生成任务或产生模型费用。
- 生产登录已增加跨进程失败次数限制；生产配置拒绝默认/弱口令、复用登录口令作为会话密钥、非 PostgreSQL 存储和非本机监听。依赖审计未发现已知漏洞。
- 已执行一次数据库与证据联合备份以及隔离恢复演练；恢复出的数据库任务数和证据目录数均通过一致性检查，演练结束后临时数据库与目录均已清理。

## 6. 当前交付边界

- ISPSoft/COMMGR 结果属于厂商工具链编译和模拟器验证，不替代真实 DVP48ES300R/AS228T-A 硬件下载、I/O 点检、急停与安全回路验收。
- 当前确定性契约支持 BOOL 跨扫描状态以及 INT/REAL 组合逻辑；保留型 INT/REAL 状态（例如累加计数器）暂不进入生成流程。
- 本轮包含多周期长任务和并发压力测试，但不等同于 24/72 小时无人值守 soak。交付试运行期间应持续执行定时 canary、磁盘/数据库备份和节点健康告警。
- 模型可能在候选预算内无法生成满足固定接口或可下载工程约束的结果；系统会如实返回失败和最后诊断，不将其计为通过。
